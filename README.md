# Dogdrip Archive

개드립 인기글 아카이브입니다.

목록 상단의 검색창에서 제목으로 이전 보관 글을 찾을 수 있습니다. 검색은
브라우저에서 `archive.json`을 읽어 처리하며 검색어를 서버에 전송하거나 저장하지 않습니다.

새로 보관하는 글은 원본 댓글의 답글 구조를 유지해 들여쓰기와 구분선으로 표시합니다.
이미 평면 형태로 저장된 과거 댓글까지 구조를 복원하려면, 자동 예약 작업이 아닌
명시적인 유지보수 실행에서만 다음 환경변수를 설정합니다.

```powershell
$env:REFRESH_COMMENT_THREADS = "1"
py -3.11 dogdrip_bot\bot.py
```

## 오래된 글 별도 보관

가장 오래된 글 1076개와 첨부파일 약 2.03GB는 비공개 저장용 레포 [dogdrip-archive-old](https://github.com/pjk3864/dogdrip-archive-old)로 옮겼습니다. 해당 글은 현재 사이트 목록에서 제외되며, 저장용 레포는 Pages로 배포하지 않습니다.

cold-storage.json에 이전 범위와 검증된 보관 커밋이 기록되어 있습니다. 기존 Git 이력은 유지되므로 저장소 전체 이력 용량은 바로 줄지 않습니다. 현재 배포 대상에서 제거한 용량만 감소합니다.

추가 이전: 오래된 글 2654개와 첨부파일 5.00GB. 별도 저장용 레포에 보관된 총량은 7.03GB, 3730개 글입니다. 현재 목록에는 2141개 글이 남아 있습니다.

## 사이트 배포

`Deploy Dogdrip Site` 작업은 수집 완료 후 실행됩니다. `dogdrip_bot/build_site.py`가 현재 목록의 본문·검색 데이터·목록 페이지만 배포하고, 이미지·영상은 공개 원본 레포의 해당 커밋에 고정된 GitHub Raw 주소에서 읽습니다. 첨부파일은 계속 GitHub에 보관되며 배포 산출물에는 포함되지 않습니다. 검색 데이터 URL에도 배포 커밋을 붙여 이전 목록 캐시를 재사용하지 않습니다.

2026-10-08 추가 이전: 오래된 글 370개와 첨부파일 1,002,163,158바이트. 저장 전용 레포의 합계 4100개 글, 8,035,698,517바이트. 현재 목록 1999개 글.

### 매일 오전 10시 수집과 자동 복구

기준은 태국 시간(Asia/Bangkok) 오전 10시이며 한국 시간으로는 정오입니다. 예약 작업은 오전 9시 50분에 준비를 시작하고, 실제 수집 단계는 10시까지 기다립니다. GitHub 예약·러너 지연으로 정각 시작을 보장할 수는 없습니다.

- 수집의 일시적인 중단은 같은 실행에서 최대 3회 시도합니다. 재시도 목록과 이미 보관된 글은 보존합니다.
- 완료된 전체 수집은 `automation-status.json`에 기록합니다. 같은 날 완료된 예약·복구 실행은 중복 수집하지 않습니다. 수동 재시도 전용 실행은 전체 수집 완료로 기록하지 않습니다.
- 오전 10시 5분·20분·45분, 11시 15분에 누락된 수집과 공개 사이트 최신 상태를 확인합니다. 수집·배포 실패 후에도 복구 확인 작업이 실행됩니다. 이미 실행 중인 작업은 중복 생성하지 않으며, 연속 실패 시 별도 복구 실행은 최대 2회로 제한합니다.
- 공개 `deployment.json`의 `archive_sha`와 원본 목록의 Git blob SHA를 비교해 새 글이 아직 배포되지 않았으면 재배포합니다. 다른 커밋에서 생성한 배포라도 목록이 같으면 다시 배포하지 않습니다.
- 일부 글의 원문 접근 실패는 경고와 재시도 목록에 남깁니다. 새로 확인된 글 전체를 수집하지 못하거나 GitHub 저장 작업이 실패하면 실패 상태를 유지해 복구 대상이 됩니다.
