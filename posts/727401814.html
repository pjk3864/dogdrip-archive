보고 좀 생각해봤는데 어느정도 수식으로는 정리할 수 있을것같은데..

원래 출발하는 수를 x, 홀수일 때 곱하는 수를 a라고 하고, 홀수값이 발생하는 항들을 특수항으로 u_i 로 정의하고, u_(i-1) 에서 u_i 사이에 발생하는 짝수항 개수를 k_i, 여기에 s_i = sum(k_0...k_i) 로 정의하면

u_i = (a*u_(i-1) + 1) / 2^(k_i)) 임.

이걸 기반으로 순환의 조건을 정리해보면
1. 어떤 홀수 발생 횟수 t >= 1 에서 1보다 큰 홀수 u_0 .. u_(t-1) 이 존재하고,
2. 2^(k_i) u_i = a * u_(i-1) + 1 (i = 1...t) 이며, (위 정형화한 수식)
3. 결과적으로 u_t = u_0 이 발생함.

저거 점화식 일반항 계산해서 정리하면......

x = ( sum_(j=0)^(t-1) a^(t-1-j) * 2^(s_j) ) / ( 2^(s_t) - a^t )

로 까지는 정리할 수 있음. 그럼 이제 위 수식에 분자항을 A, 분모항을 B 라고 정의하고, 1이 아닌 값에 대한 순환의 조건을 정리하면

1. B > 0
2 ^ (짝수항들의 발생 횟수)가 a ^ (홀수항의 발생횟수) 보다 커야 함.
2. A > B
값 x 가 1보다 커야 함.
3. A % B = 0 (A 가 B 로 나누어짐)
"어떤 t >= 1 에 대해 A = Bx 를 만족하는 정수 x > 1 가 존재해야 함".

이제 모든 x 에 대해 t 가 존재하지 않음을 증명하면 됨.
