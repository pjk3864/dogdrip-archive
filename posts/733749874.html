윈도우 바탕화면에 PC 종료 아이콘 만들기 (1초 종료)

복잡한 메뉴 클릭 없이 더블클릭 한 번으로 컴퓨터를 즉시 끄는 바로가기 아이콘을 만들기

1. 바로가기 생성: 바탕화면 빈 곳을 마우스 오른쪽 클릭 -> 새로 만들기 -> 바로 가기 선택.
2. 명령어 입력: 항목 위치 입력창에 아래 명령어 중 하나를 입력하고 [다음] 클릭:
• 즉시 종료: shutdown -s -t 0 (또는 shutdown /s /t 0)
• 강제 종료(작업 중인 앱 포함): shutdown -s -f -t 0
3. 이름 지정: 바로 가기 이름을 PC 종료 또는 시스템 종료 등으로 입력 후 [마침] 클릭.
4. 아이콘 모양 변경:
• 생성된 아이콘을 마우스 오른쪽 클릭 -> 속성
• [아이콘 변경] 버튼 클릭 후 마음에 드는 전원 모양 아이콘 선택 -> [확인] 및 [적용]
5. 아이콘 더블클릭 -> 바로 종료
